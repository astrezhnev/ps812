Tidyverse

Tidyverse

Library of packages with many useful functions

1. dplyr

Manipulate and summarize data

  • filter() — keep rows that meet a condition
  • select() — choose columns
  • mutate() — create or modify columns
  • arrange() — sort rows
  • summarize() — calculate summary statistics
  • group_by() — perform operations within groups

2. ggplot2 (later)

Create visualizations

  • ggplot() — start a plot
  • geom_point() — scatterplots
  • geom_line() — line graphs
  • geom_bar() / geom_col() — bar graphs
  • geom_histogram() — distributions
  • facet_wrap() — create separate panels
  • labs() — add titles and labels

3. tidyr

Reshape and organize data

  • pivot_longer() — convert wide data to long format
  • pivot_wider() — convert long data to wide format
  • separate() — split one column into multiple columns
  • unite() — combine multiple columns
  • drop_na() — remove missing observations

4. stringr

Work with text

  • str_detect() — find whether text contains a pattern
  • str_subset() — keep only the matching elements of a vector
  • str_replace() — replace text
  • str_to_lower() / str_to_upper() — change capitalization
  • str_length() — count characters

5. readr

Import and export data

  • read_csv() — read a CSV file
  • write_csv() — save a data frame as a CSV

6. forcats

Work with categorical variables

  • fct_reorder() — reorder factor levels
  • fct_relevel() — manually change the order
  • fct_recode() — rename categories

7. lubridate

Work with dates and times

  • ymd() — convert text to dates
  • year() — extract the year
  • month() — extract the month
  • day() — extract the day

8. purrr (later)

Repeat operations across data

  • map() — apply a function repeatedly
  • Useful when you need to perform the same operation on multiple objects

The Pipe

Tidyverse-style code is built around piping: passing the result of one function straight into the next, instead of nesting functions inside each other.

The base R native pipe (|>) ships with R itself:

library(tidyverse)
sqrt(2*2)
[1] 2
(2+2) |> sqrt()
[1] 2

You will also see the magrittr pipe (%>%) in tidyverse. It works the same:

(2+2) %>% sqrt()
[1] 2

The value of piping

Piping becomes valuable when you chain several steps together. Compare:

table(ifelse(scale(log(mtcars$mpg + 2)) > 0, T, F))

FALSE  TRUE 
   17    15

The same computation, piped step by step with the native pipe:

mtcars$mpg |>
  (\(x) x + 2)() |>
  log() |>
  scale() |>
  (\(x) ifelse(x > 0, TRUE, FALSE))() |>
  table()

FALSE  TRUE 
   17    15

Mean of an indicator

Every policy item here is already coded as an indicator: 1 = support, 0 = oppose, NA = no answer. The mean of a 0/1 variable is the proportion of 1s or the share who support.

# share of respondents who support banning assault rifles
mean(ces$CC25_321a == 1, na.rm = TRUE)
[1] 0.6450968
# same thing, dplyr style
ces |>
  summarise(support = mean(CC25_321a == 1, na.rm = TRUE))
# A tibble: 1 × 1
  support
    <dbl>
1   0.645

mutate()

mutate() builds new variables. We can use this to create an indicator out of any logical condition. Remember to reassignthe new dataframe to have it stored.

ces = ces |>

group_by()/summarise()

Two of the most useful functions in dplyr are group_by() and summarise(). You can use them to compare parts of the data. To demo this we’ll switch to a simpler dataset, mtcars

Suppose we want to find the average mpg by number of gears. Rather than calculate manually:

df = mtcars

df %>%
  group_by(gear) %>%
  summarise(avg_mpg = mean(mpg,na.rm = T))
# A tibble: 3 × 2
   gear avg_mpg
  <dbl>   <dbl>
1     3    16.1
2     4    24.5
3     5    21.4

Many functions can be used in summarise, not just mean

df %>%
  group_by(gear) %>%
  summarise(avg_mpg = sum(mpg,na.rm = T))
# A tibble: 3 × 2
   gear avg_mpg
  <dbl>   <dbl>
1     3    242.
2     4    294.
3     5    107.

And we can group by multiple variables

df %>%
  group_by(gear,vs) %>%
  summarise(avg_mpg = mean(mpg,na.rm = T))
# A tibble: 6 × 3
# Groups:   gear [3]
   gear    vs avg_mpg
  <dbl> <dbl>   <dbl>
1     3     0    15.0
2     3     1    20.3
3     4     0    21  
4     4     1    25.2
5     5     0    19.1
6     5     1    30.4

Note that the resulting object is now “grouped” output. If you want to ungroup it you can use the ungroup() function

This becomes relevant if you want to group within a seqeunce of functions but not save the full df

left_join()

left_join() is one of many functions that adds columns from one data frame onto another using some shared variable(s) as a key

party_labels = tibble(
  pid3 = c(1, 2, 3),
  party_name = c("Democrat", "Republican", "Independent")
)

ces |>
  left_join(party_labels, by = "pid3") |>
  select(pid3, party_name, commonweight) |>
  head()
